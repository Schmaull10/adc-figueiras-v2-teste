# Atualizar da V1 para a V2

Ainda não é recomendado substituir a V1 principal sem primeiro testar esta preview.

Quando decidirmos fazer o update definitivo:

1. Na V1: **Definições → Exportar dados**.
2. Guardar o ficheiro JSON.
3. No GitHub, substituir os ficheiros da aplicação pelos da V2, mantendo o mesmo repositório e o mesmo URL do GitHub Pages.
4. Abrir a aplicação atualizada no mesmo browser/dispositivo.
5. A V2 tenta importar automaticamente os dados locais da V1.
6. Confirmar plantel, treinos, jogos, multas e pesagens.
7. Só depois usar a V2 como principal.

Se a migração automática não encontrar dados, o backup JSON permite recuperar a informação manualmente.
